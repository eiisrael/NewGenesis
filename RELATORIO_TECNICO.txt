RELATÓRIO TÉCNICO — NEWGENESIS 2.3.1
=====================================

Estado
------
Release candidate de estabilização da linha 2.3. A versão canônica vem de
package.json; config, health, bootstrap e providers consomem essa fonte.

Persistência e lifecycle
------------------------
- GenesisTelemetry mantém uma fila sempre tratada e entrega o primeiro erro de
  disco somente por flush(), eliminando unhandledRejection tardio.
- O shutdown é idempotente: bloqueia novas requisições, aborta controladores
  ativos, fecha o servidor HTTP e drena stores e telemetria antes da saída.
- SIGINT e SIGTERM usam o mesmo mecanismo do runtime e dos testes.

Segurança
---------
- .env, .env.local e .env.* são ignorados, exceto .env.example sem credenciais.
- Bind fora do loopback é recusado. Host e Origin externos recebem HTTP 403.
- O cabeçalho x-genesis-client não é tratado como autenticação.
- CSP permanece sem unsafe-inline. O CSS da voz é um asset same-origin.
- Permissions-Policy libera microfone somente para self.

Orçamentos
----------
Tetos default: 4 rotas; 5 requests comuns; 14 requests com ferramentas;
12 rodadas; 12.000 tokens de contexto; 8.192 tokens de saída.

Contratos efetivos: overview local 0; análise/diagnóstico 3; resposta comum 4;
mudança comum 6; mudança ampla 14. Deadlines: 90, 180 ou 240 segundos,
conforme o contrato. Não há retry remoto escondido.

Ferramentas
-----------
Leitura: até 220 linhas e 8.000 caracteres por chamada. run_project_check
prefere check somente quando o script agrega sinais de verificações distintas;
a allowlist, o cwd isolado, o ambiente reduzido, o timeout e a sanitização são
preservados. No Windows, npm.cmd é invocado por cmd.exe com comando interno
fixo, sem shell baseado em conteúdo do modelo.

Voz
---
A camada usa o mesmo composer. SpeechRecognition/speechSynthesis são opcionais;
sem elas o texto continua habilitado. O smoke real cobre UI/estilo, console,
atalho de teclado, ARIA e degradação. O áudio não é armazenado pelo Genesis;
o fornecedor do navegador pode processar reconhecimento online.

CI
--
Actions com runtime interno Node 24; matriz Linux Node 20/22/24 e Windows
Node 22; job Chrome para voz; job isolado para npm run check do SupremeMind.

Garantias preservadas
---------------------
Free-only; overview ASTRAEON local; budget explícito; sem falso sucesso em
streaming; análise separada de mutação; escrita confinada; exclusão explícita;
ledger; redaction; memória local; SupremeMind seguro; compatibilidade Windows.

Arquitetura P2
--------------
A separação ampla de rotas HTTP, APIs Neural/SupremeMind e execução de chat foi
deliberadamente adiada. Nesta rodada, apenas lifecycle/shutdown foi extraído,
pois era necessário para corrigir a race sem refatoração destrutiva.
