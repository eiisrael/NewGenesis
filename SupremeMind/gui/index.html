Primeiros passos: o fluxo correto

O SupremeMind funciona melhor quando você segue esta ordem. Ela evita consultas sobre índice antigo e reduz o risco de alterar arquivos sem verificar dependentes.

01Carregar projeto

Selecione a pasta raiz que contém o código real.

02Inicializar

03Indexar

05Gerar contexto

Monta um pacote compacto para o agente de IA.

06Analisar impacto

07Editar e testar

Quando devo usar Atualizar?

Depois de editar arquivos, trocar de branch, executar git pull, aplicar um patch ou concluir uma tarefa. A atualização incremental reaproveita arquivos cujo hash não mudou.

GLOSSARY

O que significam os conceitos

Estes termos aparecem no Dashboard, Galaxy, busca, contexto e análise de impacto.

Índice

Arquivo local com o conhecimento estrutural extraído do projeto.

Arquivo

Unidade de código ou configuração analisada pelo indexador.

Símbolo

Classe, função, método, estrutura, chave ou título detectado.

Aresta

Ligação entre dois arquivos: dependência, chamada ou coalteração Git.

Bacia

Grupo de arquivos que converge para o mesmo núcleo estrutural.

Atrator

Arquivo central que representa o núcleo dominante de uma bacia.

Centralidade

Estimativa da importância de um arquivo dentro do grafo.

PageRank

Algoritmo usado para distribuir importância pelas conexões.

Caller

Arquivo que chama ou depende do arquivo analisado.

Callee

Arquivo chamado ou utilizado pelo arquivo analisado.

Órbita

Vizinhança de entradas, saídas e níveis ao redor de um arquivo.

Impacto

Estimativa de quantos dependentes podem ser afetados por uma mudança.

BM25

Busca lexical que valoriza termos importantes e raros.

Vetor semântico

Representação numérica local usada para aproximar significados.

Coalteração Git

Arquivos modificados juntos repetidamente no histórico.

Token

Unidade aproximada de texto consumida pelo contexto da IA.

L0

Núcleo de maior prioridade selecionado para a tarefa.

L1/L2

Arquivos prioritários e vizinhos estruturais do núcleo.

Memória

Decisão persistente que influencia futuras consultas.

Hash SHA-256

Identificador usado para saber se um arquivo realmente mudou.

TROUBLESHOOTING

Erros e dúvidas comuns

Abra uma pergunta para ver a causa provável e o procedimento recomendado.

Os cartões do Dashboard mostram “—”.
O projeto ainda não possui índice carregado. Abra Projeto, clique em Inicializar e depois em Indexar. Se você trocou de pasta, confirme o caminho no topo.
A busca não encontra uma função que existe.
Execute Atualizar, confirme que o arquivo não está em uma pasta ignorada e tente uma consulta mais descritiva. Macros complexas, reflexão e chamadas dinâmicas podem não ser resolvidas completamente pelo parser atual.
Quando usar Reindexação total?
Use após alterar dimensões vetoriais, regras estruturais, muitos diretórios ignorados, atualizar a versão do parser ou suspeitar de índice inconsistente. No uso diário, prefira Atualizar.
O Git aparece como OFF.
Verifique se o Git está instalado e se a pasta analisada é um repositório. A indexação continua funcionando, mas as relações de coalteração ficam indisponíveis.
O score de busca baixo significa que o arquivo está errado?
Não necessariamente. O score serve para ordenar candidatos. Abra os melhores resultados, confira símbolos, órbita e dependências no código real antes de concluir.
Contexto maior é sempre melhor?
Não. Contexto excessivo pode diluir a tarefa. Comece com 4.000–8.000 tokens para trabalhos normais e aumente somente quando o módulo realmente envolver muitos arquivos.
Qual diferença entre Impacto e Órbita?
Impacto percorre dependentes e estima o risco de mudança. Órbita mostra entradas, saídas e vizinhança estrutural sem resumir tudo em uma classificação de risco.
O Galaxy substitui a leitura do código?
Não. Ele facilita a orientação arquitetural, mas relações de baixa confiança e comportamentos dinâmicos devem ser verificados diretamente nos arquivos.
Onde os dados são salvos?
O índice e as memórias ficam na pasta local .suprememind/ do projeto. A configuração principal fica em suprememind.config.json.
Posso expor a GUI na internet?
Não é recomendado. Mantenha em 127.0.0.1. Exposição em rede exigiria autenticação, TLS, firewall e uma revisão específica de segurança.
